# Fishy Pond Fish Assets

172 pond sprite symbols: 149 normal pond fish plus 23 Treasury loot symbols. Each symbol is stored in the shared SVG sprite sheet.

## Fishy design rules
- rounded, friendly mascot silhouettes
- thick dark outline
- pale belly and expressive face
- simple readable fins/tails
- tier color accents
- species-specific silhouettes and markings
- small thematic accessories only when the loot-table name calls for one

Treasury symbols are distinct loot-object icons and exclude the two timeout items. Their symbols use the same dark outlines and simple, high-contrast fills so they remain readable in the Pond UI.
