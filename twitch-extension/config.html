Fishingbot / Setup

Connect the video component

Streamer setup

  1. Install and run the Fishingbot desktop app.
  2. Open Fishingbot Control Centre → Channel connection → Connect account and approve the one-time login code.
  3. Open your creator dashboard → Extensions and activate Fishingbot Video Component on your channel.

What viewers see

The component provides live channel totals, community leaderboard and loot catalogue. The interactive world map is private and appears only inside My Account → World Map, where linked players can unlock and upgrade areas directly on the map and open Tides Kingdom features. Public catalogue views are served by the shared Fishingbot relay using the streamer's running local app.

Enable Identity Linking in the Extension capabilities. Viewers watching another channel can choose Share Account Identity in My Account and approve Twitch's permission prompt to access their own inventory, Fishdex, progression, purchases, perks, Personal Pond and trades. When the streamer opens FishingHub on their own channel, Twitch does not show an identity-sharing prompt to the broadcaster; Fishingbot instead verifies the signed broadcaster role against the authenticated desktop connection for that same channel. Private requests are handled by the streamer's local Fishingbot database; no database or Extension Secret is exposed to viewers.

For the Extension version you intend to run, add exactly https://fishingbot-extension-relay.onrender.com under Allowlist for URL Fetching Domains (not Image Domains or Media Domains), then save and activate that same version. The allowlist controls HTTPS requests made by the viewer's Extension iframe; it is separate from the streamer's desktop WebSocket connection. If the desktop says Connected but viewers see a relay error, check the active version's URL Fetching Domains setting. The component reports a specific connect-src Content Security Policy error when Twitch blocks the request. The streamer must keep Fishingbot running and connected to the channel for private actions and live public catalogue requests. Relay diagnostics use https://fishingbot-extension-relay.onrender.com/health; it must return JSON with ok: true.

My Account and Twitch identity

If you are the broadcaster viewing your own channel, use Connect channel profile; Twitch intentionally does not open the Share Identity prompt for the channel owner. Fishingbot verifies the channel against the desktop app that is already authenticated to Twitch. If you are a regular viewer, select Share account identity and approve Twitch's prompt. If no prompt appears, verify Identity Linking is enabled for the active Extension version.

Viewer connection troubleshooting

Some browser privacy features and ad blockers can prevent the Twitch Extension from reaching the relay, even while the streamer's desktop app is connected. Brave users can open the lion icon on the Twitch channel page and lower Shields for Twitch, then reload the player. In uBlock Origin, AdBlock, AdGuard, Ghostery or network-level filters, allow fishingbot-extension-relay.onrender.com. The Extension cannot reliably identify which blocker caused a failed request, so this warning is a troubleshooting hint rather than a confirmed detection.

If the browser console reports a Twitch connect-src Content Security Policy violation, add https://fishingbot-extension-relay.onrender.com under URL Fetching Domains for the currently activated Extension version, then save and activate that version. A browser-blocker issue is separate from the streamer desktop WebSocket connection.
